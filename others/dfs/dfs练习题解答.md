# DFS 练习题解答

---

## 第1题：电话号码的字母组合

| 角色 | 内容 |
|------|------|
| 决策 | 当前数字对应的字母选哪个 |
| 状态 | `idx`（处理到第几个数字） |
| 约束 | 无（每个数字的字母天然独立，不会重复） |
| 终止 | `idx == len(digits)` → 记录结果 |

**关键点：** 和子集/全排列不同，这题每一层的"候选集"不同（由当前数字决定），但结构完全一样，`idx` 推进即可。无需 `used[]`。

## 第2题：N皇后

| 角色 | 内容 |
|------|------|
| 决策 | 第 `row` 行的皇后放在第几列 |
| 状态 | `row`（当前处理到第几行） |
| 约束 | `col_used[]`、`diag1_used[]`、`diag2_used[]`（列、正斜线、反斜线是否被占） |
| 终止 | `row == n` → 计数 +1 |

**关键点：** 每行只放一个皇后，所以"行"天然不冲突，状态只需要 `row`。约束需要同时排除列和两个方向的斜线：正斜线 `row-col` 相同，反斜线 `row+col` 相同。

## 第3题：分割回文串

| 角色 | 内容 |
|------|------|
| 决策 | 从当前位置 `start` 开始，切多长的子串 |
| 状态 | `start`（当前处理到字符串哪个位置） |
| 约束 | 只有切出来的子串是回文串，才能进入下一层 |
| 终止 | `start == len(s)` → 记录结果 |

**关键点：** 决策是"切割点在哪"，而不是"选哪个字符"。循环枚举 `end` 从 `start` 到 `n-1`，如果 `s[start:end+1]` 是回文串就递归。约束内嵌在循环里，不是单独的 `used[]`。

## 第4题：岛屿数量

| 角色 | 内容 |
|------|------|
| 决策 | 向上下左右哪个方向扩展 |
| 状态 | 当前格子坐标 `(row, col)` |
| 约束 | 不越界、是陆地 `'1'`、没访问过（访问过的改为 `'0'`） |
| 终止 | 越界或遇到水/已访问 → 返回 |

**关键点：** 这题 DFS 的用途不是"枚举所有方案"，而是"连通性标记"。外层主循环遍历所有格子，遇到 `'1'` 就启动一次 DFS 把整个岛沉掉（标记为 `'0'`），计数 +1。`used[]` 被原地修改网格替代。

## 第5题：表达式加括号

| 角色 | 内容 |
|------|------|
| 决策 | 以哪个运算符作为"最后一步运算"来分割表达式 |
| 状态 | 当前处理的子表达式字符串 |
| 约束 | 无 |
| 终止 | 字符串里没有运算符（纯数字） → 返回该数字 |

**关键点：** 这题是"分治型 DFS"，和前几题的"路径构建型"不同。遍历每个运算符位置，把表达式切成左右两半分别递归求所有结果，再两两组合。子问题是更短的表达式，而不是"更长的路径"。

## 第6题：单词搜索

| 角色 | 内容 |
|------|------|
| 决策 | 下一步往上下左右哪个方向走 |
| 状态 | 当前格子坐标 `(row, col)` + 已匹配到单词的第 `idx` 个字符 |
| 约束 | 不越界、当前格子字符匹配、没有访问过（`visited[][]`） |
| 终止 | `idx == len(word)` → 返回 True；越界或不匹配 → 返回 False |

**关键点：** 状态是二维的：位置 + 匹配进度，两者缺一不可。和岛屿题类似，`visited` 需要回溯（进入时标记，退出时取消），因为不同路径可以经过同一格子。

---

## 第7题：括号生成

| 角色 | 内容 |
|------|------|
| 决策 | 下一个字符放 `(` 还是 `)` |
| 状态 | `open`（已放左括号数）、`close`（已放右括号数） |
| 约束 | `open < n` 才能放 `(`；`close < open` 才能放 `)` |
| 终止 | `open == n && close == n` → 记录结果 |

**关键点：** 约束直接决定了搜索树的形状，非常干净。`close < open` 这个条件保证了任意前缀合法（右括号不超过左括号）。这题没有 `used[]`，约束完全由两个计数器表达。
